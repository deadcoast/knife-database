# docs/dev-spec — open cases

Each subdirectory here is an **open MIVIM dev-spec case**: one development
effort, three files — `design.md` (DS-1), `requirements.md` (DS-2),
`TODO.md` (DS-3) — instantiated from the templates in
`.claude/skills/mivim-agent-spec/templates/`.

Open means accountable: every case here must reach its
`checkpointTriggerFooter` and be closed out to `docs/closed/<case>/`.
An empty directory is the healthy state — it means nothing is drifting.

Workflow: `.claude/skills/mivim-agent-spec/SKILL.md` (the hub) ·
`.claude/skills/closing-out-docs/SKILL.md` (the close-out mechanism) ·
`docs/CHANGELOG.md` (the living record).
