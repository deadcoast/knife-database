# docs/closed — the case files

Every document here has been **closed out**: its canon is untouched, every
drift since authorship is annotated inline in hidden `<!-- CHANGELOG_REFERENCE -->`
comments citing `docs/CHANGELOG.md`, and it was archived here. A closed doc
is safe to read as history and unsafe to cite as current — the annotations
tell you which is which, line by line.

The workflow is defined in `.claude/skills/closing-out-docs/SKILL.md`.
